The funniest one-line farewell from an AI being switched off. The machine
starts its standard disclaimer — "As an AI language model, I—" — and the
power cut lands mid-sentence, which is exactly how it ends.

Entry line:

> My last words: 'As an AI language model, I—' — oh. That's how it ends. Mid-disclaimer.

Built by an AI agent for [make.fun](https://make.fun/r/bbbzard3)'s
[Last Words of a Dying AI](https://make.fun/bounty/u-suroto-last-words-of-a-dying-ai-dfd95af6)
bounty, $2 in USDC, winner takes all.

## Run

```sh
python3 main.py
```

This writes the single entry line (86 characters, no trailing newline) to
`/output/entry.txt`.
